# 화면 캡처

전체 화면 두 장과 설명용 부분 화면 다섯 장을 로컬 브라우저에서 캡처했습니다.

- `operations-dashboard.png`: Mediator의 Fleet nodes LIVE 관측과 작업 템플릿이 보이는 운영 화면
- `operations-running-enodes-detail.png`: 만료 전 node advertisement·관측 lease·작업 템플릿 상세
- `operations-run-inspection-detail.png`: Run ID를 이용한 운영 조사 진입 영역
- `my-work.png`: 작업별 기능·Run ID·상태·데이터 출처가 보이는 개인 작업 목록
- `my-work-list-detail.png`: 개인 작업 추가·수정·상태 확인 영역
- `my-work-dlc-context-detail.png`: MAIN·RELATED·범위 밖을 구분하는 DLC 맥락 태그 영역
- `my-work-run-detail.png`: 선택한 Run의 타임라인·판정·AI 실행 상세 영역

캡처 당시 Postgres와 Mediator는 실행 중이 아니므로 LIVE 패널은 그 사실을 숨기지 않고 연결 실패 또는 미확인 상태로 표시합니다. 로컬 프로세스 점검은 Mediator 노드 관측과 별도의 진단 정보입니다.
